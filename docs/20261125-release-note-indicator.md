# リリースノートの新着表示を丸印へ変更

- 設定タブと設定内のリリースノート項目にあった「新着」の文字を廃止し、各アイコン右上の丸印に変更した。
- 既存のヘッダーに使っていたオリーブ色を `Colors.light.accent`（`#838A2D`）/ `Colors.dark.accent`（`#9DA348`）として定義した。
- 丸印は共通の `NotificationIcon` で描画し、背景色の縁を付けてアイコンと区別する。読み上げでは新しいお知らせの存在を伝える。
- 例：未確認の告知がある時は歯車アイコンの右上に丸印が付き、履歴を開くと消える。確認位置や移行処理は既存の仕組みを使う。
- 小さな表示調整のため、アプリの版上げや新しい告知は追加していない。エージェント向け運用ガイドを更新した。

## 検証

- 変更ファイルのESLintはエラーなし（既存の未使用変数の警告2件）。原稿検証、既存11件の単体テスト、Webビルドは成功。
- 全体の型チェックには従来の14件のエラーが残り、今回の追加エラーはない。
- 実際のNotificationIconを使った独立プレビューで、ライト・ダーク表示、43pxと22pxのアイコンの丸印の位置、表示フラグ切替で2個から0個へ消えること、文字バッジがないことをブラウザー確認した。プレビューは認証やアプリ本体を変更せず、git管理外で作成した。
