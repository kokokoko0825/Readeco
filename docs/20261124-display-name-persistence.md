# 表示名を再ログイン後も保持する修正

Playwrightで本番サイトを操作し、設定で表示名を変更しても再読み込みすると以前の名前に戻る問題を再現した。例えば「Readeco動作確認A」を「Readeco動作確認A更新」に保存すると直後の表示は変わるが、再読み込み時に元へ戻った。

変更前はFirestoreだけに表示名を保存していたため、ログイン時の同期がFirebase Authenticationに残る古い名前で上書きしていた。設定の保存処理を `updateUserDisplayName` にまとめ、Authenticationの表示名を更新してから、個人設定とフレンド検索用プロフィールを更新する。

認証中の利用者のUIDを使用し、未ログイン・空の表示名は拒否する。ユーザー情報の本人限定ルールと公開項目の制限は維持する。

変更ファイルのESLintはエラーなし（設定画面に既存の未使用変数警告1件）。Webビルドが成功した。ブラウザーでの最終確認結果は、本番のユーザー操作検証記録にまとめる。
