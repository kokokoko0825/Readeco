# リリースノート運用の実装

2026-11-25。アプリ版 1.1.10。

## 変更内容と理由

- `constants/release-notes.json` を告知の正本にした。不変ID・順序・タイトル・日付・通知種別・変更の分類を持ち、アプリの版と告知の表示条件を分離した。
- 既存7件を移行し、公開日・対応版・変更内容を維持した。旧本文の「修正:」等は分類に移し、見出しを追加した。今回の告知を加え計8件。
- `/updates` に全件を読める履歴ページを追加。設定から遷移でき、公開情報の告知に限りログイン不要で共有URLからも読める。認証が必要な他画面の制御は維持した。
- 自動モーダルを廃止。通知対象の新着は設定タブとリリースノート項目へ表示する。
- 確認位置はFirebase UID別の端末ローカル保存に変更。履歴がレイアウトされフォーカスを得てから保存する。初回は現在位置を基準とし、既知の旧版は対応する順序へ移行する。旧キーはロールバック互換のため残す。
- UIDごとの非同期処理を直列化し、保存失敗時に確認済み扱いにしない。例：順序10を確認後に8までの旧ビルドへ戻しても、保存値10は下がらない。
- `package.json` を技術版の正本にし、`app.config.ts` と画面から参照。生成HTMLのsoftwareVersionにも同じ版を使う。
- PWAキャッシュ名は最終配信ファイルとWorkerテンプレートの内容ハッシュから生成。手動でキャッシュ版を上げる作業をなくした。別用途のキャッシュは削除しない。
- 原稿検証、単体テスト、同一原稿からのGitHub Release本文生成を追加。GitHub Actionsは秘密値や依存インストール不要の検証のみ行い、新しい本番デプロイ経路は追加していない。

## エージェント向けの運用

[RELEASE_NOTES_GUIDE.md](RELEASE_NOTES_GUIDE.md) を現行仕様へ全面更新した。[AGENTS.md](../AGENTS.md) と既存 [AGENT.md](../AGENT.md) の両方から参照できる。

ガイドには、告知する変更の判断、JSONの例、初回・旧キー移行・アカウント切り替え・ロールバック、検証、本番コミットSHAの照合、タグとGitHub Release作成の順序を記載した。

例：新しい告知の原稿を追加後、`pnpm run check:releases`、`pnpm run test:releases`、`pnpm run build:web` を実行する。Releaseの本文は `pnpm run release:notes 20261125-release-history /tmp/readeco-release.md` で正本から生成できる。

## 検証

- `pnpm run check:releases`：8件の原稿を検証して成功。
- `pnpm run test:releases`：11件成功。初回、旧7版の移行、UID分離、通知なし、保存失敗、並行保存、ロールバック、不正値・不正原稿、キャッシュ生成を確認。
- `pnpm run build:web`：静的Web出力と配信ファイルの後処理に成功。Service Workerのプレースホルダーが内容ハッシュへ置換されることを確認。
- Expoの最終公開設定：versionが1.1.10になり、既存のプラグイン等の設定を引き継ぐことを確認。
- 変更ファイルのESLint：エラーなし。既存のSettings.tsxの未使用変数borderDefaultの警告1件が残る。
- 全体の `pnpm exec tsc --noEmit`：変更前と同じ14件の既存エラーが残る。スキャナー・Google認証・Firebase等の既存型エラーで、今回の変更箇所に追加のエラーはない。Expo Routerの型は開発サーバー起動で再生成して確認した。
- ビルド済みページをPlaywrightで確認：ログインなしで8件の履歴を表示、デスクトップ1200pxとモバイル390pxで横にはみ出さない、ダークモード、戻る操作、ログインなし閲覧でUID付き確認位置を書かないことを確認。ブラウザーのコンソールエラーは0件。
- GitHub Release用原稿を指定IDからファイル出力できることを確認。

認証済み実アカウントでの新着バッジの見た目・消去は今回のブラウザー確認に含めていない。確認位置・新着判定の各条件は上記単体テストで検証した。Orcaのブラウザーは作成直後のタブを取得できなかったため、画面確認にはPlaywrightを使用した。

## 運用上の境界

確認位置は端末間や同一UIDの複数タブ間で即時同期する仕組みではない。原稿はプレーンテキストとして表示し、外部HTML実行・外部CMS・新しい認証権限・秘密値は追加していない。公開済みIDや順序の変更禁止は運用ガイドで定め、検証は現在の配列内の整合性を対象とする。
