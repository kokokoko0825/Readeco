# Readeco 1.1.4

## 今回の更新

- ホームの本を長押しした際に、画像の保存・共有メニューが表示される問題を修正。
- 長押しした際に、青いテキスト選択ハンドルが表示される問題を修正。
- 操作例: 1巻を長押しし、2巻をタップしてグループにまとめる。

## リリースノートの表示

`app.json` と `package.json` のバージョンを1.1.4に更新。既存の `@readeco_last_seen_version` を使い、ログイン後に保存済みバージョンが1.1.4と異なる場合に自動表示する。表示時に1.1.4を保存するため、次回以降の起動では自動表示しない。

モーダルは現在のアプリバージョンに一致するリリースノートだけを表示する。過去の1.1.3のデータは履歴として残すが、今回のモーダルには表示しない。設定から手動で開いた場合も1.1.4のみ表示する。

## 検証

- 変更ファイルのESLintとWebビルドが成功。
- モックによる既存Providerの実行で、旧バージョンからの更新時と初回訪問で表示、同じバージョンの再起動と未ログイン時は非表示、モーダルに過去の更新が含まれないことを確認。
- 本番ブラウザでのログイン後の表示は未確認。

## リリース後のバージョン判定修正

本番のHTMLは新しいビルドを配信していたが、ビルド内のExpo設定に古い1.1.3の情報が残っていた。旧実装の `Constants.expoConfig` を介さず、`app.json` のバージョンを直接参照して表示するノートを選ぶよう修正。PWAキャッシュ名もv4へ更新し、古いキャッシュを削除する。ビルドキャッシュをクリアして再ビルドする。

修正後のESLint・キャッシュクリア付きWebビルドが成功し、1.1.4のノートを選ぶことをモックで検証。再デプロイが成功（固定URL: https://f260a3d2.readeco.pages.dev）。本番HTMLのバンドル一致と、配信されたService Workerのv4キャッシュを確認済み。
