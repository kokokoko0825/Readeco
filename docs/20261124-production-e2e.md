# 本番Webのユーザー操作検証（2026-11-24）

## 結果と対象

Playwrightで `https://readeco.org` を実際に操作し、ユーザー情報の分離後も、新規登録、ログイン、設定、書籍登録・削除、フレンド検索・追加・削除が動作することを確認した。認証・Firestore・楽天APIのレスポンスはモックしていない。

独立した2つのブラウザーコンテキストでテストアカウントA/Bを作成し、Aの書籍をBからフレンド経由で表示する流れを検証した。既存ユーザーのアカウントやデータは操作していない。デスクトップ幅と390×844のスマートフォン相当の表示で確認した。

## 確認した操作

| 操作 | 結果 |
| --- | --- |
| 未ログインでサイトにアクセス | ログイン画面へ遷移 |
| テストアカウントA/Bの新規登録 | 本棚へ遷移し、個人設定・公開プロフィールを作成 |
| 表示名の保存 | 画面に反映。再読み込み時の不具合を発見して修正（下記） |
| 再読み込み・サインアウト後の再ログイン | 修正後は変更した表示名、メール、蔵書を保持 |
| サインアウト後に設定URLへ直接アクセス | ログイン画面へ戻る |
| 手動入力で書籍を登録 | 本棚と書籍詳細へ反映 |
| タイトル検索 | 「吾輩は猫である」で30件の結果を表示 |
| 検索結果からの登録 | 「吾輩は猫である改版」を登録し、詳細にISBN等を表示 |
| ISBN検索 | `9784101010014` で該当書籍を表示 |
| 登録済みISBNの再登録 | 「既に登録されています」と表示し、重複登録しない |
| 存在しないフレンドID | 「ユーザーが見つかりませんでした」と表示 |
| BからAのIDでフレンド追加 | 成功し、Aの蔵書と詳細を表示 |
| 同じフレンドの再追加 | 「既にフレンド登録されています」と表示 |
| フレンド削除 | 設定の一覧から削除 |
| 表示名修正後のフレンド再検索 | 更新した表示名で追加でき、蔵書も表示 |
| 自分の書籍の削除 | 手動登録・検索登録の両方を削除でき、本棚が空になる |
| 新刊画面 | 発売中・予約販売中を切り替えでき、対象なしの状態を表示 |
| モバイル幅でのフレンド画面 | カード・タブを表示し、横方向のはみ出しなし |

例えば、Aが追加した「Readeco E2E 検証用の本」を、BがAのユーザーIDを指定して追加し、フレンド画面から書籍詳細まで開けることを確認した。

## ブラウザーの認証状態を使ったアクセス権確認

Bのログイン状態で、ブラウザーからAの `users` と `publicProfiles` を取得するリクエストも検証した。個人設定はHTTP 403、公開プロフィールはHTTP 200で、返る項目は `userId` と `displayName` だけだった。認証トークンは記録に出力していない。

## 見つかった表示名の問題と修正

設定から表示名を変更すると、その時点では保存されるが、再読み込みすると元の名前に戻る問題を再現した。Firestoreの表示名だけを更新しており、ログイン時の同期がAuthenticationに残った以前の名前で上書きしていた。

`updateUserDisplayName` でAuthenticationの表示名も更新するように修正し、本番へ反映した。修正コミットは `2f2c7903565994a5754fdf0999e49fda967e315f`。配信バンドル `entry-207bace96655476d18b52fe2a147ebae.js` を読み込んだブラウザーで、保存→再読み込み→サインアウト→再ログインを実施し、変更した名前が保持されることを確認した。[修正内容](20261124-display-name-persistence.md)

変更ファイルのESLintはエラーなし（既存の未使用変数警告1件）。WebビルドとCloudflare Pagesの本番デプロイが成功した。

## 記録と確認範囲の限界

ブラウザーの未処理JavaScript例外は発生しなかった。意図的に確認した403の拒否や重複追加のエラー表示、画面切り替えに伴うFirestore通信の中断、既存のReact Native Webの警告は、正常操作での失敗と区別した。

Googleログインの本人操作、メール変更・パスワード再設定メール、実機カメラのバーコード読取、iOS/Androidネイティブ版、Safari/Firefox、オフライン動作は未検証。新刊は対象なしの画面を確認したもので、新刊が存在する場合の全条件を確認したわけではない。

終了後、作成したテストアカウント2件と、個人設定・公開プロフィール4件、最後のフレンド関係1件を削除した。テスト書籍2件は画面から削除済みで、テストアカウント・プロフィール・書籍・フレンド関係の残存がないことを管理APIで確認した。既存ユーザーのデータは変更していない。

テストアカウントの認証情報はGit除外の `.env.e2e.local` へ一時保存し、削除確認後にファイルも削除した。公開用コードや検証報告へ認証情報は記載していない。スクリーンショット・ブラウザー記録はローカルの `docs/20261124-production-e2e-artifacts/` に保持する。
